# Google Cybersecurity Professional Certificate  
Welcome to the **Google Cybersecurity Professional Certificate Assignment Collections** repository!

This repository is a collection of assignments, projects, and exercises completed as part of the **Google Cybersecurity Professional Certificate** program.

---

## 📜 About the Certificate  
The Google Cybersecurity Professional Certificate equips learners with foundational and in-demand cybersecurity skills, preparing them for roles in the cybersecurity domain. Topics include:  
- Foundations of Cybersecurity
- Play It Safe: Manage Security Risks
- Connect and Protect: Networks and Network Security
- Tools of the Trade: Linux and SQL
- Assets, Threats, and Vulnerabilities
- Sound the Alarm: Detection and Response
- Automate Cybersecurity Tasks with Python
- Put It to Work: Prepare for Cybersecurity Jobs
